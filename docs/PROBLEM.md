# PROBLEM — 거래내역으로 월간 지출 리포트 만들기

작성 2026-10-27. 상태: **가설**. 사용자 검증 전(아래 "검증할 것" 참고).

## 사용자와 계기
- 사용자: 카드 2–3장 + 은행 계좌 1–2개를 쓰는 개인(또는 가계부를 쓰는 사람). 1차 사용자는 레포 주인 본인.
- 계기: 매달 초 "지난달 얼마 썼지? 어디에 많이 썼지?"를 알고 싶을 때. 또는 예산을 넘었는지 확인할 때.

## 지금 하는 방법과 걸리는 시간
- 카드사·은행 사이트에서 CSV/엑셀을 내려받아 엑셀에서 정리 → 30–60분/월.
- 귀찮은 지점 (= 이 챗봇이 풀어야 할 것)
  1. 내보내기 형식이 회사마다 다름: 인코딩(cp949), 앞쪽 설명 줄, 맨 아래 합계 행, `12,300원` 같은 문자열 금액, `2026.09.03` 같은 날짜.
  2. 취소·부분취소 건을 원거래와 상계해야 함.
  3. 은행 출금 중 **카드대금 결제**는 카드 내역과 이중으로 잡힘.
  4. 할부는 "결제 총액"과 "이번 달 청구액"이 다름. 해외 결제는 USD와 원화 환산이 따로 있음.
  5. 카테고리가 없거나 회사마다 다름 → 규칙으로 분류해야 함.
  6. 결과를 매번 같은 형식(합계, 카테고리별, 전월 대비, 예산 초과)으로 보고 싶음.

## 성공의 정의
- 사용자가 파일을 올리고 한국어로 물으면, **숫자가 맞는** 답과 `outputs/`의 리포트를 받는다.
- 숫자 정확도: 원 단위 일치(해외는 0.01 USD). 틀린 숫자 하나가 리포트 전체의 신뢰를 깎으므로, **pass^3(3번 다 맞음)** 을 주 지표로 본다.
- 시간: 질문 하나에 2분 이내(현재 CLI·effort=max 기준선은 eval로 측정).
